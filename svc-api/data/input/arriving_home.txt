The smart home has two floors. On the ground floor there are the Living Room, Kitchen, Entry Hall and Garage.
On the upper floor there are the Bedroom and Bathroom.

The Living Room contains a Smart TV, Smart Speakers, a Presence Sensor and a Multimedia Hub.
The Kitchen contains a Presence Sensor, a Smart Fridge, a Smoke Sensor and a Home Automation Gateway.
The Entry Hall contains a Front Door Sensor, a Smart Lock, a Presence Sensor and Smart Lights.
The Garage contains a Presence Sensor and a Garage Door Sensor.
The Bedroom contains a Motion Sensor, a Temperature and Humidity Sensor, Smart Blinds, Smart Lights, a Bedroom Thermostat and a Comfort Hub.
The Bathroom contains a Motion Sensor and a Presence Sensor.

The ArrivingHomeRoutine starts when the Front Door Sensor or the Garage Door Sensor detects movement.
The system then performs a verification step called CheckPresence in the Living Room using the Presence Sensor.
If no one is present, the routine turns on the Smart Lights in the Entry Hall.
After that, it checks the temperature in the Bedroom using the Temperature and Humidity Sensor and adjusts it through the Bedroom Thermostat.
Finally, the routine turns on music in the Living Room using the Smart Speakers and the Multimedia Hub.
